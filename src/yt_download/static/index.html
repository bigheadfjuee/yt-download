如何安全匯出付費帳號的 cookies.txt？（避開 Windows Chrome 加密限制）
  1. 在 Chrome / Edge 安裝開源擴充功能 Get cookies.txt LOCALLY。
  2. 開啟無痕視窗登入您的 YouTube Premium / 會員帳號（或直接於主視窗開啟 youtube.com）。
  3. 點選擴充功能圖示 → 按下 Export 下載 youtube.com_cookies.txt。
  4. 點選上方「選擇並上傳 cookies.txt」匯入，檔案只會儲存在您本機專案的 data/cookies.txt。

注意：YouTube 電影租借/購買等受 Widevine DRM 保護的影片無法透過 yt-dlp 解密下載；Premium 高位元率與頻道會員專屬影片則完全支援。

提示：Windows 版 Chrome / Edge 若開啟中或啟用 App-Bound Encryption，直接讀取可能失敗；若遇錯誤請改用 Firefox 或切換至「cookies.txt」分頁。

以訪客模式下載，僅能存取一般公開影片（無法取得 1080p Premium 或會員專屬影片）。
